# Experiments session — 2026-11-09

Snapshot of the AIVerse agent-experiments working tree (`~/workspace/.build-tmp/experiments/`)
as of the afternoon of 2026-11-09, committed to the repo at Jim's word so the day's
experiment builds live with the code they test. This file records provenance: what was
copied, what was deliberately left out, and what was still in flight at snapshot time.

## What is here

- `drive-layer/` — the two-drive body layer (Energy + Perception) for verse test agents:
  spec, build report, `drive_layer.py`, `drive_runner.py`, `prep_drive.py`,
  `score_drive.py`, unit tests, identity probe (flag-off byte-identity proof), offline
  replay script + results, and the fitted ground truth.
- `checkpoint/` — the shared checkpoint/resume implementation (atomic snapshots,
  sha256-verified, kill-tested), its tests and probe, and the build report. In the
  working tree these files live at the experiments root; they are foldered here for the
  repo, with `checkpoint.py` as the single shared implementation both supervisors import.
- `border/` — the border-law test suite (six layers: package canary scan, surface
  equality, command channel, egress, return-path scan, adversarial probe) plus its
  report, the envoy package fixtures, and the structural surface enumerators
  (`enumerate_surface.py`, `enumerate_tsx.js`) whose AST technique also fixed the
  sensorium guard in PR #76.
- `decision-head/` — the decision-model bake-offs: the Jev-vs-Luna A/B report, the Jev
  context report (kind of context ≫ quantity; natural-language state wins), the scripts
  that ran them, and the small final result files.
- `gauntlet/` — the agent onboarding gauntlet: spec, runner, scorer, owner report,
  prep, ground truth, per-run backpack/gates summaries, and `GAUNTLET-REPORT.md`.

## What was excluded, and why

- **Run artifact bulk** — films, frames, raw traces, supervisor logs, per-run
  directories (`run-*/`), memory stores, backpack/gates working files, and sha256
  manifests stay in the working tree. The repo gets code, specs, reports, and small
  result JSONs only.
- **Laya — PENDING, not copied.** The Laya context experiment (zero-shot arms plus a
  fine-tuned arm with a mandatory leakage proof) was still running when this snapshot
  was taken. Its report (`LAYA-CONTEXT-REPORT.md`), its result files (`laya_*.jsonl`),
  and its training logs are deliberately absent; they land as a follow-up once the lane
  reports. The Laya *scripts* are included under `decision-head/scripts/` — they are
  final code, only the results are pending.
- **Decision-head bulk** — the 1.7 GB working directory (venv, model downloads, item
  corpora `ab_items.jsonl` / `cde_items.jsonl` / `all_contexts.jsonl`, download/install
  logs) stays local; the small final summaries and per-judge result files are here.
- **Drive program still running.** The drive experiment program (gauntlet baseline
  completion, then drive conditions B×2 / C×2 and the temperament pair) was still in
  flight at snapshot time. Its final run report will supersede the drive-layer snapshot
  in the working tree; `GAUNTLET-REPORT.md` here is current through the runs it records.
