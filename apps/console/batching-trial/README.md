# Batching trial — experiment record (tmp/batching-statics)

**Question (Jim, 2026-11-15):** the LOD trial showed simplification
cannot move draw calls. Can runtime batching of the city's static
geometry — (a) same-material merging, (b) 128 m cell-split instancing,
(a)+(b) combined — move draw calls AND fps on the real scene?

**Verdict: SHIP the combined mechanism.** P1 draw calls 8,948 → 1,458
(−83.7%); orbit 18,274 → 1,797 (−90.2%); settled orbit frame time
~9,689 ms → ~317 ms (~30×) under SwiftShader. Merge-only is cheaper
still on calls (1,100) but pays +30% rendered triangles at P1;
cells-only does NOT ship (no call reduction, +2–4%). Costs of the
combined build: ~203–214 MB resident baked geometry and 6.3–7.3 s
bake at district load; originals are retained hidden for colliders.
GLB bytes are unchanged (the transform is runtime/in-memory). A GPU
fps check is still owed before any production enable — absolute fps
is not measurable on the SwiftShader rig. Full record:
[`TRIAL-NOTES.md`](TRIAL-NOTES.md); plan: `BATCHING-PLAN.md` (written
for this trial; originally kept alongside the LOD trial's notes, now
filed here).

## Contents

- `BATCHING-PLAN.md` — scope (static bazaar/city geometry only),
  ship bar, measurement protocol.
- `TRIAL-NOTES.md` — census, per-variant delta table, methodology
  corrections, costs, tooling evaluation (`@zkmake/three-batch`
  rejected — see notes).
- `census.py` — offline GLB census of in-scope statics.
- `measure.mjs`, `film.mjs`, `diag*.mjs` — the measurement/filming
  rig (the LOD trial's settled-plateau protocol on current main).
- `runs/` — per-variant evidence: `film.mp4` (H.264) + `film.json` +
  `meta.json` for baseline / merge / both; `meta.json` for census /
  cells. The films' individual source frames (`runs/*/frames/`) are
  not in this PR — they are intermediates, regenerated by `film.mjs`.
- `src/features/world/bazaarBatch.ts` + the `?batch=` hook in
  `DistrictWorld.tsx` — the runtime module; default page behavior is
  unchanged (no `?batch=` param, no batching).
